Privacy Policy

Documentary Content Studio · effective 24 November 2026

1. Who we are and who uses this tool

Documentary Content Studio ("the studio") operates a private software tool that manages the studio's own YouTube channels. The tool is used only by the studio's owner, who owns or manages every channel it connects to. It is not offered to anyone else.

2. YouTube API Services

This tool uses YouTube API Services. By connecting a channel to the tool, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data the tool accesses and why

Permission (Google scope)What it allowsWhat we use it for
youtube.readonlyView the connected channel and its videos Confirm the right channel is connected; list the channel's own uploads to prevent duplicate uploads

The tool does not access messages, subscriber lists, monetization or payment data, or any channel that the owner does not own or manage.

4. How the data is processed

  • All YouTube API data is stored only on the owner's own computer.
  • AI assistant (Anthropic): the owner uses Claude Code, an AI assistant provided by Anthropic, to run the studio. When the owner asks the assistant to look at the channels' statistics, the relevant data (for example a video's views or retention values) is sent to Anthropic's servers so that the assistant can answer, and is processed under Anthropic's terms and privacy policy. This happens only on the owner's request, only for the owner's own channels, and the answers are seen only by the owner. Anthropic acts as an agent approved by the owner; the data is not published or passed on by the studio.
  • No derived metrics: the tool shows YouTube's official values unchanged. It does not create new or derived metrics, scores or averages from YouTube API data. The studio's own editorial predictions (for example which moments of a video it expected viewers to leave) are kept and shown separately, clearly marked as the studio's own.
  • Only the official API: the tool accesses YouTube exclusively through the official YouTube Data and Analytics APIs. It does not scrape YouTube or Google pages, does not use YouTube autocomplete, and does not download YouTube videos or captions.
  • YouTube API data is not sent to any other service. Research tools the studio uses for topic ideas receive only search terms, never YouTube API data from this tool.
  • The studio does not sell, rent or share YouTube API data, does not use it for advertising, and does not combine it with data about any person.

5. Storage and retention

  • Sign-in tokens (OAuth refresh tokens) are stored only on the owner's computer, in a local folder of the tool. They are never printed, e-mailed or uploaded anywhere, and are sent only to Google's sign-in service.
  • YouTube Analytics data (statistics and retention reports) is kept as long as it is needed to evaluate the studio's videos. The tool re-confirms at least every 30 days that it is still authorized, and always before using stored data again after a pause of more than a day (for example when the computer was switched off). If authorization cannot be confirmed for 30 days, all YouTube API data and tokens for that channel are deleted.
  • Other YouTube API data (such as video titles from the channel's upload list) is refreshed within 30 days; if it is not refreshed, it is deleted.
  • This website uses no cookies, no analytics and no advertising.

6. Revoking access and deleting data

Access can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked through the tool, the token is revoked at Google immediately and the stored tokens and YouTube API data for that channel are deleted at once (at the latest within 7 days). When access is revoked through Google's page, the tool detects that the token no longer works and deletes the stored data within 30 days. Deletion can also be requested by e-mail (below) and is completed within 7 days.
